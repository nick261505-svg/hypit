# 글로픽 동물 모음 쇼츠

여러 사건을 단순히 이어 붙이지 말고 하나의 명확한 주제로 **새로운 이야기 순서**를 만든다. 여러 원본을 새로 찾아야 할 때는 먼저 [glopick-animal-scout](../glopick-animal-scout/SKILL.md)의 검색·원본 검증 기준으로 후보군을 만든다. [참고 쇼츠 분석](references/reference-analysis.md)은 구조를 이해하는 용도다. 원본 장면·문구·음악·효과를 복제하지 않는다. 이 스킬은 기존 `astra-capcut-video`의 단일 구조 영상 형식을 대체하지 않는다.

## 선정

1. 주제를 한 문장으로 정한다. 예: `동물이 사람을 먼저 도운 순간`, `서로 다른 동물의 예상 밖 반응`. 사건들이 같은 주제에 답하지 않으면 다른 편으로 분리한다.
2. 각 후보에서 **상황 → 결정적 행동 → 확인 가능한 반응**을 실제 화면으로 확인한다. 결정적 장면이 작거나 흐리거나, 설명을 지어내야 감동이 성립하면 제외한다. 시작에는 가장 강한 시각적 질문, 끝에는 가장 만족스러운 해소를 놓는다.
3. 다른 원본의 동물을 같은 사건이나 같은 개체처럼 연결하지 않는다. 연출·AI 생성·실제 기록 여부가 불명확하면 확정적인 사실 문구를 쓰지 않는다.
4. 영상별 최초 촬영자와 권리자, 영상·현장음·음악·썸네일 장면의 허용 범위를 확인한다. 여러 영상을 합치거나 크롭·자막을 넣어도 사용 허가가 생기지 않는다. 권리가 불명확하면 공개하지 않고 검토용 초안으로 표시한다. 기존 [글로픽 권리 기준](../astra-capcut-video/references/glopick-rights.md)을 적용한다.
5. 현재 글로픽 제작 소스는 YouTube의 크리에이티브 커먼즈 필터로 찾은 뒤 **영상별 CC BY 표기와 원 촬영자**를 확인한 것부터 우선한다. Instagram이나 일반 YouTube 영상은 참고 자료로만 두며, 별도 허가 없이 편집 타임라인에 넣지 않는다.

## 구성

- 내레이션은 선택 사항이다. 없는 편은 음악과 **직접 쓴 짧은 한국어 화면 문구**, 컷 순서, 리듬으로 주제에 새로운 의미를 더한다. 원본을 거의 그대로 모은 영상은 만들지 않는다.
- 각 사건의 시작·행동·반응만 남긴다. 사건마다 같은 표제어를 반복하지 말고 전체 주제를 묶는 제목과 사건별 짧은 문구를 쓴다. 화살표·원·확대는 실제 봐야 할 행동을 가리킬 때만 사용한다.
- 기존 백조 프로젝트의 프레임과 내레이션 방식을 기본값으로 덮어쓰지 않는다. 이 형식의 독립적인 9:16 레이아웃을 설계하고 사용자가 원하는 경우에만 로고·흰 상하단을 가져온다.
- 원본의 영어 자막, 기부 문구, 채널 문구가 새 문구와 겹치면 먼저 다른 구간을 고른다. 꼭 필요한 장면만 크롭 또는 국소 처리하고 결과 프레임을 확인한다. 출처를 숨겨 자체 촬영처럼 보이게 하지 않는다.
- 음악·효과음도 권리를 확인한다. 음소거 상태에서도 행동과 반응이 이해되는지 확인한다.

## 산출물과 검토

선정 단계에서는 주제, 원본별 URL·최초 제작자·권리 상태, 장면 시각, 행동·반응, 9:16 선명도, 채택 이유를 기록한다. 제작 단계에서는 시간별 컷 계획, 화면 문구 원고와 SRT, 출처 기록, 편집 가능한 CapCut 프로젝트를 만든다. 내레이션이 없으면 SRT는 **화면 문구**임을 명시한다. 자막은 한두 줄로 자연스럽게 나누고 실제 행동에 맞춘다.

제작을 요청받았을 때는 **실제 채택 영상 파일과 쓸 수 있는 컷을 확보한 뒤** CapCut 프로젝트를 만든다. 영상이 없는 색상 슬레이트나 임시 이미지로 채운 프로젝트를 완성본이라고 전달하지 않는다. 원본·화질·사용권을 충족하는 컷이 모자라면 영상 제작을 보류하고 확인된 후보와 부족한 부분을 정확히 보고한다.

검증된 프로젝트 구조나 사용자 제공 템플릿을 쓰되 사용자의 마우스·키보드를 잠그는 데스크톱 제어는 하지 않는다. 실제로 CapCut UI를 열어 보지 않았다면 UI 검증을 했다고 주장하지 않는다. MP4 내보내기와 게시는 사용자가 별도로 요청할 때만 한다.

최종 검토에서는 원본별 출처·사용권, 장면의 진위, 9:16 가독성, 첫 2초의 질문, 마지막 해소, 문구와 화면의 일치, 음악 권리, 여러 사건의 구분을 확인한다. 내레이션이 없어도 글로픽의 독자적인 기획과 실질적인 편집 기여가 화면에 보여야 한다. [YouTube 재사용 콘텐츠 정책](https://support.google.com/youtube/answer/1311392?hl=ko)은 내러티브가 거의 없는 단순 모음을 수익화 부적합 사례로 든다. 이는 저작권 허가와 별개다.
