# 글로픽 영상 선정·2차 창작 기준

## 참고한 영상과 확인 범위

- [남의 영상 저작권 문제 없이 쓰는 방법](https://www.youtube.com/shorts/fSR0gsVgn_k): 자동 생성 자막에서 CC 영상 탐색과 새 대본 작성 조언을 확인했다.
- [유튜브 정지 절대 없는 저작권 2차 창작 가이드](https://www.youtube.com/shorts/T-Gr_x10zWw): 제목과 화면에서 재편집·가공을 권하는 내용을 확인했다. 자막 원문은 제공되지 않아 발언 전체를 검증하지 못했다.
- [다른 사람의 영상을 문제없이 사용하는 방법](https://www.youtube.com/shorts/DCykwpKATBo): 화면에서 YouTube의 Creative Commons 검색 필터와 CC BY 설명을 확인했다. 자막 원문은 제공되지 않았다.
- 사용자가 보낸 반복 URL은 같은 영상이다. 위 세 URL이 고유한 참고 영상 세 편이다.

이 영상들은 아이디어를 얻는 자료다. “CC 필터를 누르면 무조건 안전하다”거나 “재편집하면 절대 정지되지 않는다”는 보증으로 받아들이지 않는다. YouTube는 출처 표기, 짧은 사용, 번역·재편집만으로 사용권이 자동으로 생기지 않는다고 설명한다. [저작권에 대한 일반적인 오해](https://support.google.com/youtube/answer/2797449?hl=ko)

## 두 가지 별도 통과 조건

1. **원본 사용권:** 영상, 음성, 음악, 사진, 썸네일용 장면에 대해 글로픽이 해당 방식으로 이용할 권리를 확인한다.
2. **글로픽의 독자적 가치:** 자체 조사, 사실 확인, 새 대본과 관점, 내레이션, 의미 있는 편집으로 원본과 구별되는 작품을 만든다. 이는 저작권 허락과 별개의 YouTube 재사용 콘텐츠·수익 창출 판단이다. 허락을 받아도 재사용 콘텐츠 심사에서 탈락할 수 있다. [YouTube 채널 수익 창출 정책](https://support.google.com/youtube/answer/1311392?hl=ko)

둘 중 하나라도 확인되지 않으면 공개용 영상으로 승인하지 않는다. 분석·기획·로컬 편집 초안은 권리 상태를 `미확인`으로 표시할 수 있다.

## 후보 영상 선정

### 쇼츠 화면 품질 확인

권리 확인 전에 원본의 시작·중간·결말을 실제 9:16 글로픽 프레임으로 미리 본다. 파일 해상도가 1080p 이상이어도 피사체가 멀리 있는 장면, 흐린 기록 영상, 세로 크롭 후 핵심 행동이 작아지는 영상은 제작 후보에서 제외한다. 화면 확대나 인위적 선명화로 부족한 원본 화질을 통과 처리하지 않는다. 60초 동안 피사체와 행동이 선명하게 보이는 서로 다른 장면이 충분한지도 확인한다. 콘도르 방사 영상은 이 시각 품질 기준을 통과하지 못해 제작 대상에서 제외했다.

우선순위는 다음과 같다.

1. 직접 촬영하거나 글로픽을 위해 별도로 제작한 영상.
2. 권리자로부터 YouTube 업로드, 자르기·번역·내레이션 추가, 썸네일 사용, 상업적 사용·수익 창출 여부까지 명시적으로 허락받은 영상.
3. 실제 권리자가 CC BY로 배포했고 영상 안의 제3자 음악·영상·이미지 권리도 확인한 자료. YouTube 검색 필터는 후보 탐색용이며, 개별 영상의 설명·라이선스·최초 제작자와 권리 범위를 확인한다. [YouTube 라이선스 유형](https://support.google.com/youtube/answer/2797468?hl=ko)
4. 확인된 퍼블릭 도메인 또는 별도 스톡 라이선스의 영상을 해당 조건 내에서 사용.
5. YouTube 앱의 공식 Shorts 리믹스 도구로 허용된 부분을 도구의 범위 안에서 사용. 이것이 다운로드 후 CapCut에서 재편집할 일반적 권리를 주지는 않는다. [Shorts 리믹스 안내](https://support.google.com/youtube/answer/10623810?hl=ko)

인기 영상이더라도 권리자·이용 범위가 불명확하면 **참고용**으로만 둔다. 사건의 사실관계는 조사해 별도 원고로 만들 수 있으나 원본의 영상·대사·고유한 편집·음악을 무단으로 복제하지 않는다. 같은 실제 사건의 새 작품을 만들려면 직접 촬영, 적법한 대체 영상, 허락받은 자료를 사용한다.

## CC BY 자료 사용 기록

- 작품 제목, 저작자, 원본 URL, 라이선스 이름과 URL, 확인 날짜, 확인 화면을 저장한다.
- 변경·번역·재편집을 했다면 그 사실을 설명란에 표시한다. YouTube는 작품 제목·저자·출처 URL·라이선스 정보를 권장하며, 한국저작권위원회는 CC BY 4.0에서 변경 사실 표시를 안내한다. [YouTube 표기 안내](https://support.google.com/youtube/answer/2797468?hl=ko), [한국저작권위원회 FAQ](https://gongu.copyright.or.kr/gongu/bbs/B0000023/list.do?menuNo=200210)
- 업로더가 촬영자·권리자인지, 영상에 들어간 음악·방송 클립·사진·타인 음성이 별도 권리 대상인지 확인한다. 확인이 안 되면 해당 요소를 사용하지 않는다.
- CC BY와 CC BY-NC·ND 등을 혼동하지 않는다. 글로픽의 상업적 사용·수정 가능 여부를 라이선스별로 확인한다.

## 글로픽이 새로 만드는 부분

- 원본의 문장·자막을 직역하거나 같은 순서로 옮기지 않는다. 사건을 추가 자료와 대조하고 글로픽 관점의 새 대본을 쓴다.
- 원본 클립은 허락 범위에서 이야기를 설명하는 데 필요한 부분만 쓴다. “몇 초 이하는 안전”이라는 고정 기준은 없다. [저작권에 대한 일반적인 오해](https://support.google.com/youtube/answer/2797449?hl=ko)
- 자체 내레이션, 사실 설명, 맥락, 결과 또는 배울 점을 넣는다. 로고·흰 여백·자막·배속·색 보정만 추가한 영상은 독자적 가치로 간주하지 않는다. [재사용 콘텐츠 정책](https://support.google.com/youtube/answer/1311392?hl=ko)
- 원본의 낚시·기부 안내 문구처럼 새 내레이션과 충돌하는 화면 텍스트는 가능하면 해당 장면을 피한다. 필요한 경우 허락 범위 안에서 국소적으로 정리하되 원본 제작자 표기를 숨겨 소유를 오인시키지 않는다.
- 음악·효과음·이미지·썸네일도 각각 권리를 확인한다. 실사처럼 보이는 AI 재연은 실제 사건 영상으로 소개하지 않는다.

## 제작 전 승인 기록

각 후보의 `production.json` 또는 제작 메모에 아래를 적는다.

| 항목 | 기록 내용 |
| --- | --- |
| 원본 | 제목, 최초 제작자, URL, 게시일 |
| 권리 근거 | 직접 제작 / 허락 문서 / CC BY / 퍼블릭 도메인 / 스톡 / 플랫폼 리믹스 |
| 허용 범위 | 자르기·번역·내레이션·썸네일·YouTube 게시·수익화·기한·지역 |
| 별도 요소 | 음악, 외부 영상, 사진, 로고, 음성의 권리 상태 |
| 표시 의무 | 저작자, 출처 URL, 라이선스, 변경 여부 |
| 새 기여 | 글로픽의 조사 자료, 새 대본, 해설 관점, 편집 변화 |
| 상태 | `권리 확인` / `미확인` / `사용 불가` |

**공개 기준:** `권리 확인`이고 글로픽의 새 기여가 구체적으로 설명될 때만 게시를 진행한다. 예외적인 저작권 제한·공정이용 주장에 의존할 경우에는 별도 법률 검토 대상으로 표시한다. 현재 백조 구조 초안은 `production.json`에 재게시 허락이 확인되지 않았다고 기록되어 있으므로 공개 기준을 아직 통과하지 않았다.
