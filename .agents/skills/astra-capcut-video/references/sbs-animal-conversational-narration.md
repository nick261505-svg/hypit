# 글로픽 자연스러운 동물 이야기 내레이션 기준

참고: [달리(SBS) 동물농장 영상](https://www.youtube.com/watch?v=KditRlcs27w). 영상, 음성, 음악, 고유한 표현은 사용하지 않는다. 자동 생성 자막은 오류가 있으므로 대사 인용 자료로 쓰지 않는다.

## 적용할 리듬

1. 첫 장면의 이상한 점을 짧은 질문이나 관찰로 열고 답은 바로 말하지 않는다.
2. 화면에서 확인되는 행동을 따라 한 장면에 한 사실만 전한다. 이유나 감정은 근거 없이 단정하지 않는다.
3. 긴 설명 뒤에는 짧은 반응이나 호흡을 둔다. 매 문장을 `~습니다`로 끝내지 않는다.
4. 발견 → 예상과 다른 행동 → 해결 또는 변화 순서로 장면을 구성한다. 실제 영상에 없는 반전은 만들지 않는다.
5. 현장의 말과 소리를 살릴 수 있으면 내레이션을 잠시 비운다. 원본 방송의 인터뷰나 음악은 허락 없이 복사하지 않는다.
6. 마무리는 결과를 보여주는 장면에 맞춰 짧게 끝낸다. 감정을 강요하는 교훈이나 과장은 피한다.

## 대본 점검

- 첫 두 문장이 시청자의 궁금증을 만드는가?
- 모든 문장이 해당 장면에서 확인되는 내용인가?
- 한 문장에 정보가 둘 이상 쌓이면 쪼갰는가?
- 소리 내어 읽었을 때 일상 대화처럼 들리는가?
- 화면 속 핵심 순간에 설명이 지나치게 겹치지 않는가?

예시 구조(새로 쓴 형식): `어? 저기 뭔가 걸렸네요. / 가까이 가보니 여우 한 마리예요. / 그런데 그물은 생각보다 꽉 조여 있었습니다. / 한 올씩 끊어내자, 여우가 다시 움직이기 시작합니다.` 사실과 장면에 맞춰 다시 작성할 것.
