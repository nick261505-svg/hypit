# 글로픽 동물 영상 탐색

이 스킬은 **소재 선정**에 사용한다. 사용자가 제작까지 요청하면 선정 결과를 기존 `astra-capcut-video`(단일 사건) 또는 `glopick-animal-montage`(여러 사건)로 넘긴다. 링크와 조회수만 모으지 말고 실제 화면에서 시청자가 느낄 이유를 확인한다. [플랫폼별 검색법](references/search-playbook.md)을 필요할 때 읽는다.

## 검색 전에 정할 것

- 형식: 한 사건의 위기·해결인가, 한 주제로 3개 안팎의 독립 사건을 엮을 것인가.
- 주된 감정은 하나로 고른다. **감동**은 선택·수고·관계와 그 결과가 보일 때, **웃음**은 예상과 다른 행동과 즉각적인 반응이 보일 때, **반전**은 앞 장면의 합리적 예상이 뒤 장면에서 실제로 뒤집힐 때다. 다친 동물·슬픈 음악·놀란 표정만으로 감정을 판정하지 않는다.
- 검색 문장은 `동물/상황 + 관찰 가능한 행동 + 반응/결말 + 원본 단서`로 만든다. `감동 동물`, `animal rescue`, `funny pets`처럼 광범위한 단어만 쓰지 않는다. 한국어·영어와 촬영자·보호소·구조단체 계정을 함께 탐색한다.

## 후보 수집과 검증

1. 글로픽 제작용 소스는 현재 **YouTube 검색의 `필터 → 크리에이티브 커먼즈`**에서 먼저 찾는다. 긴 원본과 Shorts를 모두 보고 각 영상 상세 설명을 펼쳐 `크리에이티브 커먼즈 저작자 표시 라이선스(재사용 허용)`를 개별 확인한다. 검색 필터 결과만으로 확정하지 않는다. Instagram 릴스·계정·해시태그·본문은 소재와 최초 원본을 추적하는 참고 자료로 탐색할 수 있지만, 별도 사용 허가나 명시적 재사용 라이선스가 확인되지 않은 릴스는 제작 소스로 넣지 않는다. 공개 조회가 로그인·연령 제한으로 막히면 `화면 미검증`이라고 기록한다. 다른 사람의 요약만 보고 영상 내용을 단정하지 않는다.
2. 재업로드·뉴스·모음 계정은 **원본을 찾는 단서**로만 사용한다. 워터마크, 최초 게시일, 계정의 연속 게시물, 원본 설명, 동일 장면의 역검색으로 촬영자·최초 게시물을 추적한다. 원본을 못 찾으면 `원본 미확인`으로 남긴다.
3. 영상의 시작·핵심 행동·반응/결말을 직접 확인하고 시각을 적는다. 9:16에서 동물과 행동이 선명한지, 원본 자막·기부 문구·로고가 겹치는지, 나래이션 없이도 이해되는지 확인한다. 끝에 실제 해소 장면이 없으면 감동·반전을 제목으로 약속하지 않는다.
4. 제작 후보는 별도로 **권리 검토**한다. 플랫폼에 공개되어 있거나 다운로드/리믹스 버튼이 있어도 다른 플랫폼의 CapCut 편집·YouTube 재게시 허가로 간주하지 않는다. 원본별 영상·음악·제3자 요소·썸네일 사용권을 확인한다. CC BY도 업로더가 권리자인지 살핀다. 권리 미확인은 탐색 후보로 남길 수 있지만 `공개 가능`으로 표시하지 않는다. [기존 글로픽 권리 기준](../astra-capcut-video/references/glopick-rights.md)을 따른다.
5. 채택한 CC BY 소스마다 **제목·업로더·URL·라이선스 확인일·수정 내용**을 출처 기록에 남긴다. 원본에 다른 사람의 음악, 방송 화면, 재업로드 흔적이 있으면 그 요소의 권리도 따로 확인한다. 확인할 수 없는 음악은 음소거하고, 재업로드 의심 영상은 원 촬영자를 찾기 전까지 보류한다.

## 선정 판단

각 후보를 `결정적 행동`, `반응/결말`, `신선함`, `세로 화면 품질`, `원본 신뢰도`, `권리 상태`로 평가한다. 앞의 다섯 항목은 `강함 / 보통 / 약함 / 미확인`, 권리는 `확인 / 미확인 / 불가`로 기록한다. **결정적 행동·결말·화질 중 하나라도 약하면** 조회수가 높아도 우선 선정하지 않는다. 기존 사례에서 백조의 이물질 제거는 행동과 결과가 선명했고, 여우 구조는 예측 가능한 진행, 올빼미 방생은 어두운 결말, 콘도르 영상은 화질이 약했다. 이 관찰을 다음 탐색의 기준으로 사용한다.

단일 사건은 60초를 지탱할 시작·전개·결정적 순간을 요구한다. 모음형은 먼저 한 문장 주제를 정한 후 **서로 다른 원본**에서 주제에 맞는 장면을 찾는다. 같은 행동만 반복하지 말고 시작의 질문, 중간의 변화, 마지막의 가장 강한 반응이 되도록 묶는다. 충분한 원본과 권리를 확인하지 못하면 빈자리를 약한 장면으로 채우지 않는다.

## 결과 형식

후보마다 `플랫폼 | 원본 링크 | 최초 제작자 추정/확인 | 장면 시각 | 보이는 행동·반응 | 감정과 근거 | 9:16 품질 | 텍스트/음악 문제 | 권리 상태 | 채택/보류 이유`를 표로 낸다. 직접 못 본 것은 `미검증`으로 표시하고 인용 기사와 원본 링크를 구분한다. 모음형이면 주제별로 묶을 수 있는 **독립 원본 조합**과 컷 순서, 부족한 역할을 제시한다. 사용자가 요청한 개수를 못 채우면 검증된 수만 제시한다.

최종 선정은 `시청자에게 보이는 감정 근거`와 `제작 가능한 권리 근거`를 구분해서 보고한다. 출처 표시·번역·짧은 사용·여러 영상 합치기만으로 권리가 생긴다고 말하지 않는다. [YouTube 라이선스 안내](https://support.google.com/youtube/answer/2797468?hl=ko)와 [재사용 콘텐츠 정책](https://support.google.com/youtube/answer/1311392?hl=ko)을 확인한다.
