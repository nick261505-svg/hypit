# 플랫폼별 탐색 실무

## 검색 문장

`동물 + 문제/기대 + 행동 + 반응`으로 좁힌다. 검색 결과가 모음 영상뿐이면 자막 문장·워터마크·특이한 동물 이름으로 원본을 거슬러 올라간다.

| 목표 | YouTube 검색 예 | Instagram 검색 예 | 통과할 화면 |
| --- | --- | --- | --- |
| 감동 | `shelter dog recognizes adopter original footage`, `wildlife rescue release reaction original` | 구조단체·보호소 계정에서 `reunion`, `release`, `adoption` 릴스 | 선택/재회/방생과 상대의 반응이 함께 보임 |
| 웃음 | `dog afraid of tiny cat owner original`, `parrot copies owner reaction original` | 반려동물 주인 계정에서 `unexpected pet reaction`, `funny cat dog` 및 관련 해시태그 | 예상과 다른 행동 뒤 즉각적인 반응이 보임 |
| 반전 | `animal rescue unexpected reveal original`, `dog brings back unexpected object owner` | 게시물의 `unexpected`, `plot twist`에서 출발해 원본 계정 확인 | 앞의 예상을 뒤집는 결과가 실제 화면에 있음 |

영어 단어는 검색 예시일 뿐이다. 영상 제목의 `saved`, `cried`, `hero`, `miracle`은 화면과 별도 출처로 확인되기 전에는 사실로 쓰지 않는다. 알고리즘이 보여 주는 유사 영상만 연달아 고르면 같은 재업로드가 중복될 수 있으므로 다른 계정·검색어·플랫폼으로 교차 확인한다.

## 플랫폼별 체크

- YouTube: 검색어 입력 → `필터` → `크리에이티브 커먼즈`를 선택한다. Shorts뿐 아니라 긴 원본을 찾고 **각 영상 상세 설명의 라이선스 표기**를 다시 확인한다. 채널·업로드 날짜·설명·원 촬영자 단서도 기록한다. 필터는 후보 찾기이며 권리자 확인을 대신하지 않는다. CC BY 영상이라도 삽입 음악·방송 화면 등 별도 권리가 불명확하면 해당 부분을 제외하거나 음소거한다. 업로드 설명에는 작품 제목, 저작자, 원본 URL, CC BY 및 수정 사실을 적는다.
- Instagram: 릴스의 계정·본문·태그·연속 게시물과 링크를 기록한다. Meta는 공개 릴스가 Explore 및 해시태그 페이지에서 발견될 수 있다고 설명한다: https://about.fb.com/news/2020/08/introducing-instagram-reels/ . 실제 검색 UI는 계정과 지역에 따라 달라질 수 있다.
- Instagram 공개 링크라도 로그인·연령 제한으로 영상이 안 보일 수 있다. 그때는 웹 검색 기사·원본 계정 링크를 **탐색 단서**로만 저장하고 `화면 미검증`으로 둔다. 계정 로그인 정보를 요구하거나 접근 제한을 우회해 검증한 척하지 않는다.
- Instagram Remix/다운로드 가능 여부는 해당 플랫폼 내 기능 확인 항목이며 YouTube 게시 허가의 대체 증거가 아니다. 권리자 허락이나 명시적 라이선스가 없으면 공개용으로 선정하지 않는다.

## 모음 쇼츠 조합

먼저 `의외로 서로를 도운 동물들`처럼 한 문장 주제를 쓰고 후보별로 맡을 역할을 정한다: 첫 질문, 규칙을 보여 주는 사례, 예상 밖 변형, 가장 강한 결말. 같은 사건의 재업로드를 별개 사례로 세지 않는다. 화면에서 같은 동물·같은 날의 일로 오해할 연결을 피하고 필요하면 짧은 전환 문구로 사건을 구분한다.
